# Экспо Контакт

Статический сайт для GitHub Pages. Откройте `index.html` или разместите содержимое репозитория на GitHub Pages из ветки `main`, папки `/ (root)`.

Источники, мероприятия и начальная частичная выборка хранятся в `data/data.js`. Каталоги необходимо расширять и проверять вручную: сайт не выполняет автоматический сбор. Статусы, контакты и заметки хранятся в localStorage конкретного браузера. Для переноса используйте экспорт на странице «Мои данные».

Данные опубликованного сайта будут общедоступны; не добавляйте секреты или непубличные персональные данные в исходники. Списки могут быть предварительными; участие в выставке не доказывает потребность в подрядчике.
